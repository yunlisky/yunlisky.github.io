# yunlisky.github.io

个人小游戏合集。所有游戏都是纯静态页面，**不联网、不收集数据**，可离线游玩，部分支持安装到手机主屏（PWA）。

首页 `index.html` 是作品索引，点卡片直接开玩。

## 本站小游戏

| 路径 | 游戏 | 类型 | 说明 |
| --- | --- | --- | --- |
| `/rokkenjima/` | 六轩岛密室 | 像素推理 | 17 位来客、8 个夜晚、连续密室。读案卷、解七道推理锁、指认真凶；零失误通调用 S 评价。可离线安装 |
| `/echo-station/` | 回声车站 | 像素叙事 | 1987 年冬，废弃铁路 K-17 信号站。像素风循环叙事，6 种结局。可离线安装 |
| `/beacon/` | 灯塔 | 像素动作 | 四面都是雾，你只有一道光。转动光柱把逼近的雾影烧尽，守住八波；三盏灯、一次清场的脉冲。可离线安装 |
| `/crate/` | 推箱 | 像素解谜 | 二十关推箱子，把木箱推到发光标记上。可撤销、可重来，记录每关最少步数，难度从一步递进到二十几步。可离线安装 |
| `/hextris/` | Hextris | 街机 | 六边形俄罗斯方块，已汉化并适配移动端触控与横屏 |
| `/anbeijinsan/` | 刺杀安倍晋三 | 休闲点击 | 20 秒计分点击类小游戏，改自经典「刺杀肯尼迪」，支持自定义按键 |

各游戏源码分别位于对应子目录；`/anbeijinsan/` 为原根目录游戏迁移而来，资源路径同步迁移。

`beacon/` 与 `crate/` 是原创作品，源码在工作区根目录同名文件夹里（不随本站发布的部分见各自 `tools/`：图标生成器、无头浏览器回归探针、推箱关卡可解性体检器）。发布到本站用工作区根目录的 `deploy.js`，只同步运行期需要的文件并顺带核对 `index.html` 引用与 `sw.js` 预缓存清单。

本站内容仅供娱乐，无任何政治与商业目的。
